Every session

Every transcript on disk plus the live registry — not just the recent ones the board keeps. Rows are filenames and sizes; open one on the board to see what it cost.

Devices

Machines declared in ~/.localflow/devices.json. Sessions started here run inside tmux on the far side, so a dropped connection costs you a reconnect rather than the session. Attaching is a command you run yourself — this board starts and stops work, it does not hold a terminal open to another computer.

Cost is derived from measured tokens, not reported by the provider.
